## ما هي إضافة Claude Code؟

حصل Claude Code على **التعديلات** في الإصدار 2.1.287: وهي امتدادات قد تغيّر سلوكاً أعمق مما تستطيع إضافة تغييره، وترسم واجهتها الخاصة.

يمكن للتعديل ربط `ui.render` لرسم **صف أو شريط أو لوحة أو بطاقة** حول المطالبة، وقراءة النص الذي حددته مؤخراً باستخدام `$.ui.selection()`، وإنشاء زملاء باستخدام `agent.spawn`، وامتلاك منطقة `Client`. إذا فشل التعديل في الرسم، فإنه يفشل وحده — إذ يضمن `ui.fault` ألا يتسبب تعديل واحد معطّل في إسقاط الجلسة.

تغطي هذه القائمة التعديلات، وواجهة الإضافات والخطافات التي تُبنى عليها، والنظائر الخاصة بـ DSH وCordis. وهي لا تغطي عمداً منظومة Claude Code الأوسع: فحزمة المطالبات ليست تعديلاً.

## كيفية تصنيف الإدخالات

تكتفي معظم القوائم في هذا المجال بتأكيد الإدراج. أما هذه القائمة فتوضح مقدار ما تم التحقق منه فعلياً، ثم تتيح لك التصفية وفقاً لذلك. تصف الدرجة الأدلة، لا جودة المشروع — فالتعديل الجيد الذي لم يكتب عنه أحد بعد يظل `inferred`.

| التصنيف                                                            | المعنى                                                                                                                                                                 |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `نشرها Anthropic نفسه`                                             | نشرها Anthropic نفسه، أو قُرئت مباشرةً من سجل التغييرات الرسمي.                                                                                                          |
| `يذكر نصّه تعديلاً باسم API، أو يعلن عن إمكانية التعديل`             | يذكر نصّه جزءاً من واجهة التعديل — `ui.render` أو `ui.fault` أو `agent.spawn` أو `$.ui.selection()` أو لوحة أو شريطاً أو بطاقة — لذا يصف المؤلف شيئاً بُني على API الحقيقي. |
| `أعلن عن تعديل أو إضافة أو خطاف، لكن دون ذكر واجهة التعديل تحديداً` | يصف نفسه بأنه تعديل أو إضافة أو خطاف، لكن لا يذكر شيء في نصّه واجهة التعديل تحديداً. حقيقي، لكن غير مؤكَّد.                                                                |
