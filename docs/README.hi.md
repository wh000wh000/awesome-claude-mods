## Claude Code मॉड क्या है

Claude Code में 2.1.287 से **मॉड** उपलब्ध हुए: ऐसे एक्सटेंशन जो प्लगइन की तुलना में व्यवहार में अधिक गहराई से बदलाव कर सकते हैं और अपना इंटरफ़ेस बना सकते हैं।

कोई मॉड प्रॉम्प्ट के आसपास **पंक्ति, बैंड, पेन या कार्ड** बनाने के लिए `ui.render` में हुक कर सकता है, `$.ui.selection()` से आपके द्वारा हाल में चुना गया पाठ पढ़ सकता है, `agent.spawn` के साथ टीममेट बना सकता है और `Client` क्षेत्र का स्वामित्व ले सकता है। जो मॉड ड्रॉ करने में विफल रहता है, वह अकेले विफल होता है — `ui.fault` किसी एक खराब मॉड को पूरे सत्र को बंद करने से रोकता है।

यह सूची मॉड, उनके आधारभूत प्लगइन और हुक सतह, तथा DSH और Cordis के समकक्षों को शामिल करती है। इसमें जानबूझकर व्यापक Claude Code इकोसिस्टम को शामिल **नहीं** किया गया है: प्रॉम्प्ट पैक मॉड नहीं होता।

## एंट्रीज़ का मूल्यांकन कैसे किया जाता है

इस क्षेत्र की अधिकांश सूचियाँ केवल शामिल किए जाने का दावा करती हैं। यह सूची बताती है कि वास्तव में कितना सत्यापित किया गया है, और फिर आपको उसी के अनुसार फ़िल्टर करने देती है। ग्रेड साक्ष्य का वर्णन करता है, प्रोजेक्ट की गुणवत्ता का नहीं — ऐसा अच्छी तरह बनाया गया मॉड जिसके बारे में अभी तक किसी ने नहीं लिखा है, फिर भी `inferred` है।

| ग्रेड                                                                                     | इसका अर्थ                                                                                                                                                                                                                              |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `स्वयं Anthropic द्वारा प्रकाशित`                                                           | स्वयं Anthropic द्वारा प्रकाशित, या आधिकारिक चेंजलॉग से सीधे पढ़ा गया।                                                                                                                                                                    |
| `इसके अपने पाठ में किसी मॉड API का नाम दिया गया है, या यह मॉड क्षमता घोषित करता है`       | इसके अपने पाठ में मॉड सतह के किसी हिस्से — `ui.render`, `ui.fault`, `agent.spawn`, `$.ui.selection()`, किसी पेन, बैंड या कार्ड — का नाम दिया गया है, इसलिए लेखक ऐसी चीज़ का वर्णन कर रहा है जिसे उन्होंने वास्तविक API के आधार पर बनाया है। |
| `मॉड, प्लगइन या हुक घोषित किया है, लेकिन विशेष रूप से मॉड सतह के बारे में कुछ नहीं बताया` | यह स्वयं को मॉड, प्लगइन या हुक कहता है, लेकिन इसके पाठ में विशेष रूप से मॉड सतह का नाम नहीं दिया गया है। वास्तविक है, लेकिन इसकी पुष्टि नहीं हुई है।                                                                                      |
| `केवल शब्दावली के आधार पर मेल खाता है`                                                    | केवल शब्दावली के आधार पर मेल खाता है। इसे फ़िल्टर को ऑडिट योग्य रखने के लिए शामिल किया गया है, इसलिए नहीं कि इसे विश्वसनीय माना गया है।                                                                                                    |
