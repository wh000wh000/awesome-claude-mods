## ม็อด Claude Code คืออะไร

Claude Code เพิ่ม **ม็อด** ในเวอร์ชัน 2.1.287: ส่วนขยายที่อาจเปลี่ยนพฤติกรรมเชิงลึกได้มากกว่าปลั๊กอิน และวาดอินเทอร์เฟซของตัวเองได้

ม็อดสามารถฮุกเข้ากับ `ui.render` เพื่อวาด **แถว แถบ แพเนล หรือการ์ด** รอบพรอมป์ อ่านข้อความที่คุณเลือกไว้ล่าสุดด้วย `$.ui.selection()` สร้างเพื่อนร่วมทีมด้วย `agent.spawn` และเป็นเจ้าของพื้นที่ `Client` ได้ หากม็อดวาดอินเทอร์เฟซไม่สำเร็จ ก็จะล้มเหลวเพียงตัวเดียว — `ui.fault` ป้องกันไม่ให้ม็อดที่เสียตัวเดียวทำให้เซสชันล่มทั้งระบบ

รายการนี้ครอบคลุมม็อด พื้นที่ปลั๊กอินและฮุกที่ม็อดเหล่านี้สร้างขึ้น และสิ่งที่เทียบเท่ากันใน DSH และ Cordis โดยจงใจ **ไม่** ครอบคลุมระบบนิเวศ Claude Code ที่กว้างกว่านั้น: ชุดพรอมป์ไม่ใช่ม็อด

## วิธีจัดระดับรายการ

รายการส่วนใหญ่ในพื้นที่นี้เพียงระบุว่าอยู่ในขอบเขต แต่รายการนี้จะบอกว่ามีการตรวจสอบจริงมากน้อยเพียงใด แล้วให้คุณกรองตามนั้น ระดับจะอธิบายหลักฐาน ไม่ใช่คุณภาพของโครงการ — ม็อดที่สร้างมาอย่างดีแต่ยังไม่มีใครเขียนถึง ก็ยังเป็น `inferred` อยู่ดี

| ระดับ                                                                          | ความหมาย                                                                                                                                                                          |
| ------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `เผยแพร่โดย Anthropic เอง`                                                      | เผยแพร่โดย Anthropic เอง หรืออ่านโดยตรงจากบันทึกการเปลี่ยนแปลงอย่างเป็นทางการ                                                                                                         |
| `ข้อความของรายการระบุชื่อม็อด API เอง หรือประกาศว่ารองรับความสามารถด้านม็อด`        | ข้อความของรายการระบุส่วนหนึ่งของพื้นที่ม็อด — `ui.render`, `ui.fault`, `agent.spawn`, `$.ui.selection()`, แพเนล แถบ หรือการ์ด — ดังนั้นผู้เขียนกำลังอธิบายสิ่งที่สร้างขึ้นโดยทำงานกับ API จริง |
| `ประกาศว่าเป็นม็อด ปลั๊กอิน หรือฮุก แต่ไม่ได้ระบุรายละเอียดเกี่ยวกับพื้นที่ม็อดโดยเฉพาะ` | เรียกตัวเองว่าม็อด ปลั๊กอิน หรือฮุก แต่ไม่มีข้อความส่วนใดระบุพื้นที่ม็อดโดยเฉพาะ มีอยู่จริง แต่ยังยืนยันไม่ได้                                                                                   |
| `ตรงกับคำศัพท์เท่านั้น`                                                          | ตรงกับคำศัพท์เท่านั้น รวมไว้เพื่อให้ตรวจสอบตัวกรองได้ ไม่ใช่เพราะเชื่อว่ารายการนี้เป็นม็อด                                                                                                   |
